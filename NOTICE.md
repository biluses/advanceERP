# Notice

Vitrina is built on top of the generation studio published as
**open-higgsfield** (<https://github.com/wide-trace/open-higgsfield>), which
describes itself as "the free, open-source alternative to Higgsfield AI".

The imported foundation (catalog-driven image/video generation, the studio
surface, the platform client and poll loop, the design system) is theirs. The
vertical layer — domain, workspace, billing, presets, channels, app pages — is
this repository's own work.

At the time of import the upstream repository carried **no LICENSE file**. The
README calls the project open source, but no license text grants the rights
that word implies. Before selling or redistributing this product, confirm the
upstream license terms with its author or replace the imported foundation.
This file records the provenance so that conversation can happen with the
facts in hand.

Vitrina is not affiliated with Higgsfield AI. "Higgsfield" is used only to
name the generation platform the studio talks to.
